# Vecna — Site da Campanha

Site da campanha de D&D 5.5ª edição (2024) do grupo: lore, personagens, NPCs, e uma referência de regras em português (magias, itens, monstros, classes), baseada no SRD 5.2 (Creative Commons Attribution 4.0).

Stack: React + TypeScript + Vite + Tailwind CSS v4, com componentes no estilo shadcn/ui.

## Rodando localmente

```
npm install
npm run dev
```

## Build

```
npm run build
```

Publicado automaticamente no GitHub Pages a cada push na `master` (veja `.github/workflows/deploy.yml`).

## O que tem

- **Lore** — recapitulação da Sessão 1 (Necrotério de Thay). Conteúdo de sessões futuras fica de fora de propósito, pra não spoilar os jogadores.
- **Personagens** e **NPCs** da campanha.
- **Fotos** — links pro Drive por sessão (não hospedamos as fotos aqui).
- **Magias / Itens / Monstros / Classes** — referência de regras traduzida a partir do SRD 5.2 aberto (não copia o texto da tradução oficial em PT-BR, que tem direitos autorais).
- **Cartas para imprimir** — página separada pra selecionar magias/itens/monstros e imprimir em formato de carta.

Busca global com Ctrl+K, alternância de tema claro/escuro e idioma PT-BR/EN (útil pro conteúdo que ainda não foi traduzido).
